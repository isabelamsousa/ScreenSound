# ScreenSound 🎵

ScreenSound is an application developed in **C# with .NET**, created to practice fundamental programming concepts, project organization, and code versioning using Git/GitHub.

## 📌 Project Goal
This project was developed for learning and practice purposes, applying concepts studied throughout the course, such as:
- Project structure and layered architecture
- C# programming
- .NET development
- Visual Studio solution organization
- Code versioning with Git

## 🛠️ Technologies Used
- C#
- .NET
- ASP.NET
- Entity Framework
- HTML
- CSS

## 📂 Project Structure
The project is organized into different layers, separating responsibilities such as:
- API
- Data layer
- Models layer
- Web application
